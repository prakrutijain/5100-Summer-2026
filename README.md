# New Repository

This repository was initialized as a new workspace.

## Structure

- `src/` - application code
- `tests/` - unit tests

## Setup

1. Create a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   python -m src.app
   ```
4. Run tests:
   ```bash
   pytest
   ```
